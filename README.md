# 🔬 Tetra-Primer ARMS-PCR Primer Designer (TarmsPrimerTool)

This interactive bioinformatics tool helps design **inner primers** for Tetra-Primer ARMS-PCR. It ensures:
- Target melting temperature (Tm) match
- SNP-specific allele discrimination
- Basic primer quality checks including GC clamp and properties
- Optional support for secondary structure/dimer detection and NCBI BLAST™

---

## 🚀 Features

- Upload FASTA and SNP input files
- Auto-design of allele-specific inner primers
- Tm calculations using Wallace formula and IDT-like settings
- 3' GC clamp check
- GC content, molecular weight, extinction coefficient, and more
- Export results to CSV
- Built using **Streamlit** for fast, interactive use
